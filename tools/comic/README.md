# 畫漫畫

完整流程模式（`/test/?mode=flow`）場與場之間的劇情是一頁一頁的漫畫，翻在一大張書頁上（`public/test/src/story.js`）。這個資料夾是畫漫畫用的全部工具；這份文件是**畫風的規則**與**畫一格的做法**。規則是使用者定的，不要自己放寬；覺得哪一條擋路，先問。

畫漫畫的工具都在這裡、不在網站上：攝影棚由 `make-comic.mjs` 自己的伺服器供出來，不會被部署。遊戲執行時用得到的（書頁、14 頁的資料、拍好的圖）才在 `public/`。

## 現況

| 項目 | 狀態 |
| --- | --- |
| 劇本 | `STORY.md`：14 頁、每一格的畫面、鏡頭、字 |
| 第 1～14 頁 | 全部畫好了：`public/test/comic/p<頁>-<格>.png`，第 14 頁第 4 格是三條細長條 `p14-4a`～`c` |
| 版面 | 照格數；第 13 頁 `big: 4`、第 14 頁 `big: 5` 讓那一格最大，第 14 頁第 4 格用 `strips` 拆成三條 |
| 背景剪影 | 零件見 `studio.js` 的 `PIECES` |

## 畫風規則

1. **主體**：遊戲本身的 3D 角色擺姿勢，渲染成 2D 的光影（三階平塗加墨線），疊漫畫質感（暗部網點），**全彩**。不另外畫角色。
2. **背景**：書頁的紙色加**素色剪影**。
   - 剪影一律拿**遊戲地形的零件**（`pieces.js`：柱、旗、營帳、兵器架、城牆、王座……）拼貼，不自己畫圖形。
   - 剪影只取零件的**形狀**：一個顏色、不分階、沒有墨線、不長網點，從正面平拍、沒有透視。不拿它做遠近與空間感，所以不分深淺、不照距離縮放。
     - 例外（使用者指定）：第 14 頁第 5 格的廳，柱與旗沿著往王座收的線排、越近王座越小、錯開成平行四邊形（`skew`：直的邊照樣直，橫的邊順著那條線往王座升高），做出從王座延伸的縱深（`shots.js` 的 `hall`）。柱腳要在人物的腳後面，不然看起來像踩在柱子上。
   - 每一件放在畫面哪裡、多大，是**構圖**決定的（畫面的比例），跟 3D 場景無關。要「很遠」的格子（第 1 頁第 4 格）是把地平線拉高、背景縮成貼在地平線上的一小條。
   - **地面**是**不規則的長橫線**：從構圖給的地平線往下，幾條長短不一、兩頭收尖的長橫線，像筆一劃拉過去，畫在畫面上，近處遠處一樣粗。不規則，所以照規則 10 要夠長、夠稀疏：每一條是畫面寬的 0.16～0.5 倍，每一列最多兩條、有的列整列空著。空地不留白紙。
   - 緊張的格子用**集中線**（`focusLines`）：一圈往臉收的墨色楔形，畫在主體底下，中間留白給臉。
   - 角色碰得到的東西（國王坐的王座）才放進 3D 場景（`props`），顏色跟背景剪影一樣。
3. **取景**：多用特寫，至少裁掉一部分身體，製造張力。整隻完整入鏡的遠景只留給「很小、很孤單」那一種格子。
4. **表情**：靠眼睛與眉毛，而且只在漫畫裡出現（遊戲的眼睛不變）。例如嚇出眼淚、橫線的疲憊眼睛、一邊挑眉冒汗。
5. **線**：
   - 禁止「不完全包覆的邊線」：一個形狀的墨線要嘛整圈包住它，要嘛不畫。例如沿著眼睛下緣描半圈淚光不行；要表示淚，就在那個位置放淚珠，每一顆各自整圈包邊。
   - 眉毛、橫線眼、眼瞼那一刀是「線」本身，不是誰的邊，不受這一條限制。
   - 水滴（淚、汗）一律是橢圓，**不可以有尖角**。
   - 哭：一隻眼睛一顆**大**淚珠（左右各一顆），是**橫的**橢圓（寬比高大），掛在下眼眶。不要一排小淚珠，也不要飛出去的一串。
6. **構圖要表達關係**。範例：「王國最強的戰士」是主角昂首在前、低角度往上拍，國王在後面坐在王座上，凸顯守護與英雄感。
7. **主角固定**畫成遊戲預設那一隻：立耳犬、黃、戴漁夫帽。漫畫是事先畫好的，不跟著玩家選的動物換。
8. **回憶格**（`memory: true`）：沒有格框，暖色、褪色，邊緣暈進紙裡。
9. **字**疊在圖上，不畫進圖裡（`comic.js` 的 `say`）：
   - 旁白：`旁白：…`，放在左上角的方框裡。
   - 對白：`人名：…`，人名另起一行。
   - 心聲：沒有前綴，預設放在上方；用 `capAt: 'bottom'` 改放下方。
   - 心聲、對白有紙色描邊，壓在深色的地方也讀得到。
10. **紋理**一律用排線、網點這種**規則**的紋理：一樣大小、一樣間隔、照格子或照列排。
    - 要不規則的紋理，就必須**夠大**（一塊一塊看得出形狀），或**稀疏成叢**（幾處聚在一起、中間留白），不可以平均、密密地鋪滿一片（像雜訊、亂點、長短亂斷的線）。
    - 用亂數產生的紋理幾乎都會變成「平均密集的不規則」，先想能不能改成規則的排法。
    - 現有的：暗部網點（45° 等距格子）是規則的；地面是不規則的長橫線，靠「每條都很長、整體稀疏」符合這一條。集中線是效果線，不算紋理。

## 畫一格的流程

1. **讀劇本**：在 `STORY.md` 找那一頁那一格的畫面、鏡頭、字。在 `comic.js` 找那一頁的格數。
2. **想鏡頭**：特寫還是中景、裁到哪裡、從哪個角度、用哪個表情，對照上面的規則 3、4、6。
3. **寫 `tools/comic/shots.js`**：加一筆 `{ id: 'p<頁>-<格>', ... }`。欄位見下一節。
4. **拍**：在 repo 根目錄跑 `node tools/comic/make-comic.mjs p2-1`（不給 id 就全部重拍），一格大約 3 秒。想用瀏覽器邊調邊看：`node tools/comic/make-comic.mjs --serve`，打開它印出來的網址（← → 換一格），改了 `shots.js` 重新整理就好。
5. **看圖**：用 Read 打開 `public/test/comic/p2-1.png`。透明的地方在檢視器裡可能顯示成黑或白，都是正常的。不滿意就回到第 3 步。
6. **接進書頁**：在 `comic.js` 那一格加 `src: 'comic/p2-1.png'`，需要的話加 `focus`、`capAt`、`memory`。
7. **看整頁**：開 `/test/?mode=flow`，在主控台跑下面這段，橫向、直向都看（直向會照 `focus` 裁）：
   ```js
   const c = await import('/test/src/comic.js');
   flowArea.story.start(c.pagesOf([2]));
   ```
8. **檢查、提交**：跑 `node tools/verify-story.mjs` 與 `node tools/verify-flow.mjs`，然後 commit。一頁畫完提交一次；改了攝影棚或 `faces.js` 的能力，另外先提交。

重拍是確定的：同一份 `shots.js` 與 `faces.js` 拍出來就是同一張圖，所以要精準重現某個表情或某一格，引用那一筆設定（`face: 'shock'`、或抄那一格的 `cast`／`cam`）就好。反過來，改了 `faces.js` 裡某個表情的畫法，用到它的舊格子重拍也會跟著變。

## shots.js 的欄位

```js
{
  id: 'p1-1',              // 圖檔名，也是 comic.js 的 src
  size: [1800, 620],       // 出圖像素：比例照它在橫向版面裡那一格（見下表）
  ink: 3.5,                // 墨線幾像素（以 size[1] 的高度算）：特寫 4～4.5，中景 3～3.5
  light: [-4, 7, 5],       // 主光從哪個方向來（指向光的向量），可省略
  bg: [{ piece: 'column', x, y, size, view, tilt, flip, ...零件的參數 }],   // 背景：照構圖拼貼的剪影（見下面）
  horizon: 0.8,            // 地平線在畫面高的幾成，往下畫滿地面的排線；沒給就沒有地面
  props: [{ piece: 'throneSeat', at: [x, z], yaw }],   // 角色碰得到的道具，3D
  focusLines: true,        // 集中線，或 { n, clear, width, seed, at }
  rays: { at: [fx, fy], n, from, to, inner, width, color, alpha },   // 光芒（可以是陣列）
  speedLines: { angle, rows, band, len, width, seed },              // 速度線
  puffs: [{ x, y, r, color, alpha, n, seed }],                      // 霧與塵
  souls: [{ at: [x, y, z], yaw, scale, seed, trail }],              // 靈魂（發光的狗頭），3D；trail 是小球冒幾幀（預設 90）
  cast: [{
    who: 'hero',           // 見下面「角色」
    look: 'cat/tabby',     // who 是 'folk' 的時候：哪一隻、哪一件毛
    name: 'a',             // 同一種好幾隻時，鏡頭要對準第二隻以後的那一隻，用名字指
    at: [x, z], yaw,       // 公尺；yaw 0 = 面朝 +Z，π/2 = 面朝 +X
    speed: 4, frames: 45,  // 在跑（公尺／秒）；步態跑幾幀停在那一格，換 frames 就是換一個步伐
    air: -6,               // 在空中，值是垂直速度（負的往下掉）
    scale: 1.2,            // 整隻放大（騎士幽靈）
    alpha: 0.25,           // 半透明的那幾隻（幽靈）散到剩幾成
    shields: 3, spin: 1.3, // 國王的亡魂繞著幾面盾、盾環轉到哪個角度（盾擋到臉就轉開）
    y: 0.7,                // 墊高（坐在王座上）
    shadow: false,         // 不畫腳下的影子
    move: { ... },         // 姿勢，見下面
    tip: 0.5,              // 整隻往牠自己的 +X 側倒幾弳
    face: 'proud',         // 表情，見 faces.js
    blade: 'knife',        // 嘴裡橫咬哪一把（blade.js：主角的 knife、騎士的 knight、國王的 king）
    eyes: { lift, spread },// 畫上去的眼睛往額頭抬、往外分開多少（眼睛半高的倍數，在頭上用 3D 移，跟著頭仰、頭低走）
  }],
  cam: { focus: 'hero', yaw, pitch, dist, fov, frame: [fx, fy], roll },  // 對準那一隻的臉（特寫用這個）；roll 是鏡頭繞視線歪幾弳
  // 或 cam: { pos: [x, y, z], look: [x, y, z], fov }               // 世界座標
}
```

- **拼貼 `collage`**：`[{ cast, cam, light, front }]`，同一格裡另外幾組角色，各用自己的鏡頭與光拍，疊進同一個畫面（`front: true` 疊在主畫面上面，否則在底下）。現實裡不可能同時成立的視角（四個角落各一隻、各自一個角度，或遠處的主角貼得比透視近）在漫畫裡可以拼在一起，製造張力。例：第 7 頁第 4 格。
- **`cam.focus`**：鏡頭從那一隻的臉（兩眼中點），往世界方位 `yaw`（0 是 +Z 那一側）、仰角 `pitch`（負的是從下往上拍）退 `dist` 公尺看著臉。`frame` 是臉落在畫面上的哪裡，從正中間算、以寬高的比例表示，+y 往下。
  - 要拍到臉，`yaw` 約等於角色的 `yaw` 加減 0～0.8。
- **背景 `bg`**：`piece` 是 `studio.js` 的 `PIECES` 裡的名字（`column`、`banner`、`pavilion`、`weaponRack`、`standard`、`dummy`、`archeryTarget`、`rampart`（城牆加垛口）、`throneSeat`、`deadTree`、`well`、`house`（窄巷的連棟屋）、`sarcophagus`（石棺）、`gateway`（門洞：尖拱加兩側的牆，給 `lift` 就有鐵閘）、`dais`（王座廳的台座：台階、石台、王座、兩尊騎士石像、兩盆火）、`arcade`、`pointedArch`、`chain`、`gargoyle`、`knight`（騎士石像）……），其餘的參數原樣交給那支零件（`pavilion` 的 `R`、`h`，`rampart` 的 `from`、`to`、`h`）。
  - 剪影的底邊正中間放在畫面的 `(x, y)`（寬高的比例，y 往下），高 `size`（畫面高的比例），寬照零件的比例。超出畫面的照裁，大柱子裁出畫面就是框。
  - `view` 是零件繞直軸轉幾弳再拍（要側面就 π/2），`tilt` 往前傾、看得到一點頂，`flip` 左右翻。
  - 後面的先畫，寫在陣列後面的蓋在前面。
- **角色 `who`**：都是遊戲裡那幾隻本人，怪物是 `monster.js` 的 `makeMonsterCritter`（同一件毛、同樣大、幽靈一樣半透明），頭盔、王冠、盾照 `fight.js` 戴。同一種角色一格裡可以有好幾隻。
  - `hero` 主角（立耳犬黃、漁夫帽、高 1）、`king` 活著的國王（垂耳犬灰、王冠、高 1.4）。
  - `zombie` 殭屍、`boss`（兩倍大、頭盔）、`knight`（1.2 倍高、頭盔；劍用 `blade: 'knight'`）、`ghost` 幽靈。
  - `ghostKing` 國王的亡魂（幽靈那一件、王冠；劍用 `blade: 'king'`，盾用 `shields`）。
  - `knightGhost` 騎士幽靈：幽靈加頭盔（劇本的「先拼」），`scale: 1.2`、`blade: 'knight'`。
  - `folk` 王國的人民：`look` 給 `'cat/orangin'`、`'cat/tabby'`、`'cat/calico'`、`'dog-prick/grey'`、`'dog-drop/cow'`……
- **道具 `props`**：`{ piece, at: [x, z], y, yaw, scale }`，擺在 3D 場景裡跟角色一起拍。`throneSeat` 的座面頂在 0.5 公尺、面朝 −Z。`{ blade: 'knight', at, y, yaw, size }` 是一把掉在地上的刀劍（原本的顏色，`size` 是拿它的那一隻多高）。
- **效果**：都是效果線或大團，不是紋理（規則 10）。
  - `rays` 光芒：從 `at`（畫面的比例）往外放、等角度等寬的光，`from`／`to` 是角度範圍。中心放在畫面外很遠、`inner` 給大，光就從一條弧開始、幾乎平行（地上一整條裂縫透上來的光）。光從縫裡透上來、從誰身上擴散出去、門後的冷光。畫在角色底下、背景剪影後面（門後的光被門擋住）；`front: true` 畫在剪影前面。
  - `speedLines` 速度線：沿 `angle` 一列一列等間隔的長線，跑過去、掉下去。畫在角色底下。
  - `puffs` 霧與塵：幾團大圓聯成的形狀，沒有墨線、半透明。幽靈散掉的霧、砸起來的塵。畫在最上層。
- **姿勢 `move`**（`critter.js` 的 `moveOverlay`）：
  - `pitch`：身體仰俯，正值是低頭那一側往下。
  - `headPitch`：正值低頭、負值抬頭。`headYaw`、`headTilt` 是頭轉、頭歪。
  - `tailPitch`、`tailYaw`：尾巴。`drop`：身體下沉（負值往上）。`lean`、`twist`：上半身往側倒、扭。
  - `front`／`hind`／`knee` 加上 `legs`（0～1）：把四條腿換成那個姿勢。
  - `w`：設 1。
  - `shots.js` 開頭已經有幾組可以抄：`HEROIC`（昂首）、`SIT`（坐）、`STARTLE`（彈起來）、`DROWSY`（垂頭）、`LOOK_AROUND`（張望）。

### 出圖比例（橫向、約 1280×720 時量的）

| 一頁幾格 | 格子比例（寬 ÷ 高） |
| --- | --- |
| 3 格 | a 1.2（左邊大格，跨兩列）；b、c 1.65 |
| 4 格 | a 2.9；b 1.25；c 1.6；d 2.5 |
| 5 格 | a、b 2.1；c、d、e 1.4 |

圖在格子裡是鋪滿（`object-fit: cover`）。直向或比例不同的時候，照 `comic.js` 那一格的 `focus` 裁，例如 `'62% 40%'` 是臉的位置。所以出圖時臉不要貼著邊。

## 表情（faces.js）

現有這幾種：
- `proud`：堅定、濃眉壓下來。
- `calm`：半睜、沉穩（國王）。
- `tears`：嚇哭，每隻眼睛下眼眶一顆大淚珠、一顆汗。
- `shock`：驚醒，白眼、瞳孔一點、眉彈高、驚嚇線，每隻眼睛一顆大淚珠。
- `tired`：橫線眼加眼袋。
- `dazed`：豆眼、一邊挑眉、一顆汗。
- `pant`：喘，眼睛擠成尖朝鼻樑的「＞」、八字眉、一顆汗。
- `hope`：盼，圓的大黑眼珠、兩顆高光、眉抬高。
- `sad`：難過，八字眉、下眼眶一顆大淚珠。
- `glare`：瞪（怪物），一隻普通的眼睛（直的橢圓）塗成純紅、整圈包邊，上面斜切一刀——切線外側高、內側（鼻樑那一側）低，剩下上緣一道斜線、下緣橢圓的弧。沒有瞳孔、沒有眉毛。
- `visor`：戴頭盔的怪物瞪人，跟 `glare` 同一雙斜切的紅眼。
- `ko`：被打倒的怪物，叉叉眼（跟靈魂的叉叉同一個記號）。
- `rest`：安息，閉眼、往下彎的弧。

**怎麼運作**：拍之前把模型的兩片眼睛藏起來。從眼睛的骨頭投影出每一隻眼睛在畫面上的中心、大小（眼睛半高 `r`）、頭頂方向、鼻樑在哪一側。拍完、網點之後，用 2D 畫上去。

**單邊縮小**（漫畫的規則，跟遊戲實體遊玩時不一樣）：遠的那隻眼睛照頭**真正**側過去多少縮小——攝影棚量兩眼連線與「臉 → 鏡頭」方向的內積 d（側轉角的正弦），頭仰、頭低、身體立起來都算在裡面（`studio.js` 的 `FAR_EYE`）。側轉 6° 以內兩隻都是原尺寸；45° 以內一直畫，照開根號平緩地收，縮的幅度是遊戲的一半（13° 約九成、30° 約八成、45° 七成五）；45° 以外一刀不畫，不是線性縮到零；臉背對鏡頭（偏過 110°）兩隻都不畫——過肩、背影的格子，表情不會畫到後腦勺上。界線刻意放在正側面之後：側面（頭低一點時量起來常是 90° 多）畫靠鏡頭那一隻眼睛是刻意的畫法，不算背對。遊戲裡模型自己的遠眼收合（`critter.js`）漫畫不用。畫上去的表情（眼、眉、淚、汗）跟著同一個比例 `s` 一起縮。

**畫在穿戴上面**：漫畫的眼睛可以蓋在頭盔、面甲、帽子或其他穿戴上（遊戲裡不行）。眼睛被吻部或穿戴擋住的時候，保持正常的兩眼間距、用 `lift` 抬到看得到的地方，不要用 `spread` 把兩隻硬塞到兩側。

**跟著頭走**：`eyes` 的 `lift`、`spread` 是在頭上用 3D 移的——沿著那隻眼睛的頭頂方向往額頭抬、沿著兩眼連線往外分開，再投影到畫面上。頭仰起來或低下去，畫上去的眼睛跟著走；從下往上斜看的臉被透視壓扁，同樣的 `lift` 在畫面上移得少。

**新增表情**：在 `FACES` 加一個函式。座標是那一隻眼睛自己的：原點是眼睛中心，−y 是頭頂，+x 是鼻樑那一側，單位是 `r`。左右不對稱的用 `a.i`（第幾隻眼睛）分。畫完照規則 5 自己檢查一次。

## 踩過的坑

- **倒下的怪物**：照 `death.js` 那樣側倒（`tip`），鏡頭不高的時候只看得到肚子與四隻腳，或一整片背，讀起來是一團綠色。漫畫裡倒下的怪物趴平（`shots.js` 的 `FLOP`：下巴貼地、四腳攤開）、臉朝鏡頭、`face: 'ko'`。
- **過肩鏡頭**：鏡頭朝 +Z 看的時候，世界的 +X 在畫面的**左邊**。對準被看的那一隻（`cam.focus`），鏡頭的 `yaw` 從主角背後再偏開 0.8～1 弳，主角才不會整個擋在牠前面——擋到臉的話，畫在最上層的表情會浮在主角身上。

- **剪影裡透光的縫**：零件是一塊一塊砌的（柱子分鼓、牆分磚），縫拍出來是空的，剪影上會有一條條紙色的線。攝影棚把每一張剪影往外補幾個像素（同色錯開疊幾次）把縫合起來；新加的零件縫比較寬的話，調 `drawCutout` 裡的 `r`。

- **全黑**：毛皮與王冠的著色器要一張投影深度圖。沒有綁的話，ANGLE 會整個不畫，畫面是一片墨色。攝影棚已經讓遊戲的 `light/shadow.js` 綁一張空的；新增別的材質時注意這件事。
- **帽簷擋眼睛**：主角戴帽子，從上往下拍時帽簷蓋住眼睛。鏡頭放在眼睛高度或更低，或讓牠抬頭（`headPitch` 負值）。
- **吻部擋眼睛**：模型的眼睛貼在吻部的上角，正面或仰頭時，吻部會擋在眼睛前面。表情是畫在最上層的，擋住的眼睛也照畫，看起來會像眼睛畫在鼻子上。選側一點、低一點的角度；正面特寫用 `eyes: { lift: 0.9, spread: 0.35 }`。
- **咬刀**：刀是橫咬的，臉側過去的話，靠鏡頭那一側的刀柄（或刀身）會橫在眼睛前面——表情畫在最上層，看起來像眼睛畫在刀上。咬刀的格子讓臉幾乎正對鏡頭（相差 0.3 弳左右），刀才會橫過畫面、從嘴角兩邊伸出去。
- **抬頭加仰拍**：頭抬起來（`headPitch` 負值）又從下往上拍，吻部會整個蓋到眼睛的高度，靠鼻樑那隻眼睛會疊在黑鼻子上看不見。仰拍的時候頭放平。
- **仰拍立起來的大傢伙**（第 3 頁第 3 格的 BOSS）：從下往上看、頭又仰著，臉被頭盔帽簷與吻部夾成一條縫，眼睛在 3D 裡就藏在吻部後面，`lift` 加多少都還是壓在吻部上。讓牠低頭往下瞪（`headPitch` 加大），臉才正對低處的鏡頭；眼睛再用 `lift` 抬到吻部上面。
- **側面**：遠的那隻眼睛會自動收掉、不畫。三分之四側時，遠的那隻可能還在、卻疊到吻部上；轉多一點或轉少一點。
- **太暗**：背光時大半落在暗部，網點會很重。用 `light` 把主光轉到鏡頭這一側。
- **檔案大小**：一格 250～600 KB。全部畫完約 15 MB，之後可能要改存 WebP。
- **無頭 Chrome**：`make-comic.mjs` 找系統的 Chrome（或用環境變數 `CHROME` 指定），用的是軟體 GL，拍一格只要幾秒。不要拿它跑遊戲本身，一秒不到一幀。
