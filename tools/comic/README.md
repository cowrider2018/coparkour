# 畫漫畫

場與場之間的劇情是一頁一頁的漫畫，翻在一大張書頁上（`public/test/src/story.js`）。這份文件是**畫風的規則**與**畫一格的做法**。規則是使用者定的，不要自己放寬；覺得哪一條擋路，先問。

## 現況

| 項目 | 狀態 |
| --- | --- |
| 劇本 | `STORY.md`：14 頁、每一格的畫面、鏡頭、字 |
| 第 1 頁（兵營開場） | 已畫：`public/test/comic/p1-1.png` ～ `p1-4.png` |
| 第 2～14 頁 | 佔位（書頁上是「分格 n、待繪：…」） |
| 背景剪影 | 還沒開始。只有一個道具：王座（第 1 頁第 1 格） |

## 畫風規則

1. **主體**：遊戲本身的 3D 角色擺姿勢，渲染成 2D 的光影（三階平塗加墨線），疊漫畫質感（暗部網點），**全彩**。不另外畫角色。
2. **背景**：書頁的紙色加**素色剪影**（樹、花草、建築、道具）。剪影是一個顏色、不分階、沒有墨線。背景要等使用者說開始才畫。
3. **取景**：多用特寫，至少裁掉一部分身體，製造張力。整隻完整入鏡的遠景只留給「很小、很孤單」那一種格子。
4. **表情**：靠眼睛與眉毛，而且只在漫畫裡出現（遊戲的眼睛不變）。例如嚇出眼淚、橫線的疲憊眼睛、一邊挑眉冒汗。
5. **線**：
   - 禁止「不完全包覆的邊線」：一個形狀的墨線要嘛整圈包住它，要嘛不畫。例如沿著眼睛下緣描半圈淚光不行；要表示淚，就在那個位置放淚珠，每一顆各自整圈包邊。
   - 眉毛、橫線眼、眼瞼那一刀是「線」本身，不是誰的邊，不受這一條限制。
   - 水滴（淚、汗）一律是橢圓，**不可以有尖角**。
6. **構圖要表達關係**。範例：「王國最強的戰士」是主角昂首在前、低角度往上拍，國王在後面坐在王座上，凸顯守護與英雄感。
7. **主角固定**畫成遊戲預設那一隻：立耳犬、黃、戴漁夫帽。漫畫是事先畫好的，不跟著玩家選的動物換。
8. **回憶格**（`memory: true`）：沒有格框，暖色、褪色，邊緣暈進紙裡。
9. **字**疊在圖上，不畫進圖裡（`comic.js` 的 `say`）：
   - 旁白：`旁白：…`，放在左上角的方框裡。
   - 對白：`人名：…`，人名另起一行。
   - 心聲：沒有前綴，預設放在上方；用 `capAt: 'bottom'` 改放下方。
   - 心聲、對白有紙色描邊，壓在深色的地方也讀得到。

## 東西在哪

```
STORY.md                       劇本（頁、格、畫面、鏡頭、字）
public/test/src/comic.js       14 頁的資料：每一格的 note、say、src、focus、capAt、memory；SCRIPT 是哪一刻翻哪幾頁
public/test/src/shots.js       每一格怎麼拍：誰、站哪、姿勢、表情、鏡頭、光、道具
public/test/src/faces.js       漫畫的表情（2D，畫在拍好的圖上）
public/test/src/mode-comic.js  攝影棚：/test/?mode=comic，擺角色、拍、網點、畫表情、出 PNG
tools/make-comic.mjs           開無頭 Chrome 進攝影棚，把每一格存成 public/test/comic/<id>.png
public/test/src/story.js       書頁：滑進來、分格一格一格拼上去、翻頁
public/test/index.html         #story 底下的 CSS：版面（3／4／5 格，橫向／直向）、字、回憶格
```

## 畫一格的流程

1. **讀劇本**：在 `STORY.md` 找那一頁那一格的畫面、鏡頭、字。在 `comic.js` 找那一頁的格數。
2. **想鏡頭**：特寫還是中景、裁到哪裡、從哪個角度、用哪個表情，對照上面的規則 3、4、6。
3. **寫 `shots.js`**：加一筆 `{ id: 'p<頁>-<格>', ... }`。欄位見下一節。
4. **拍**：在 repo 根目錄跑 `node tools/make-comic.mjs p2-1`（不給 id 就全部重拍），一格大約 3 秒。
5. **看圖**：用 Read 打開 `public/test/comic/p2-1.png`。透明的地方在檢視器裡可能顯示成黑或白，都是正常的。不滿意就回到第 3 步。
6. **接進書頁**：在 `comic.js` 那一格加 `src: 'comic/p2-1.png'`，需要的話加 `focus`、`capAt`、`memory`。
7. **看整頁**：開 `/test/?mode=flow`，在主控台跑下面這段，橫向、直向都看（直向會照 `focus` 裁）：
   ```js
   const c = await import('/test/src/comic.js');
   flowArea.story.start(c.pagesOf([2]));
   ```
8. **檢查、提交**：跑 `node tools/verify-story.mjs` 與 `node tools/verify-flow.mjs`，然後 commit。一頁畫完提交一次；改了攝影棚或 `faces.js` 的能力，另外先提交。

## shots.js 的欄位

```js
{
  id: 'p1-1',              // 圖檔名，也是 comic.js 的 src
  size: [1800, 620],       // 出圖像素：比例照它在橫向版面裡那一格（見下表）
  ink: 3.5,                // 墨線幾像素（以 size[1] 的高度算）：特寫 4～4.5，中景 3～3.5
  light: [-4, 7, 5],       // 主光從哪個方向來（指向光的向量），可省略
  props: [{ shape: 'throne', at: [x, z], yaw, scale }],   // 剪影道具，座面頂在 0.5 × scale 公尺
  cast: [{
    who: 'hero',           // 'hero'（立耳犬黃、漁夫帽、高 1）或 'king'（垂耳犬灰、王冠、高 1.4）
    at: [x, z], yaw,       // 公尺；yaw 0 = 面朝 +Z，π/2 = 面朝 +X
    y: 0.7,                // 墊高（坐在王座上）
    shadow: false,         // 不畫腳下的影子
    move: { ... },         // 姿勢，見下面
    tip: 0.5,              // 整隻往牠自己的 +X 側倒幾弳
    face: 'proud',         // 表情，見 faces.js
    eyes: { lift, spread },// 畫上去的眼睛往額頭抬、往外分開多少（眼睛半高的倍數）
  }],
  cam: { focus: 'hero', yaw, pitch, dist, fov, frame: [fx, fy] },  // 對準那一隻的臉（特寫用這個）
  // 或 cam: { pos: [x, y, z], look: [x, y, z], fov }               // 世界座標
}
```

- **`cam.focus`**：鏡頭從那一隻的臉（兩眼中點），往世界方位 `yaw`（0 是 +Z 那一側）、仰角 `pitch`（負的是從下往上拍）退 `dist` 公尺看著臉。`frame` 是臉落在畫面上的哪裡，從正中間算、以寬高的比例表示，+y 往下。
  - 要拍到臉，`yaw` 約等於角色的 `yaw` 加減 0～0.8。
- **姿勢 `move`**（`critter.js` 的 `moveOverlay`）：
  - `pitch`：身體仰俯，正值是低頭那一側往下。
  - `headPitch`：正值低頭、負值抬頭。`headYaw`、`headTilt` 是頭轉、頭歪。
  - `tailPitch`、`tailYaw`：尾巴。`drop`：身體下沉（負值往上）。`lean`、`twist`：上半身往側倒、扭。
  - `front`／`hind`／`knee` 加上 `legs`（0～1）：把四條腿換成那個姿勢。
  - `w`：設 1。
  - `shots.js` 開頭已經有幾組可以抄：`HEROIC`（昂首）、`SIT`（坐）、`STARTLE`（彈起來）、`DROWSY`（垂頭）、`LOOK_AROUND`（張望）。

### 出圖比例（橫向、約 1280×720 時量的）

| 一頁幾格 | 格子比例（寬 ÷ 高） |
| --- | --- |
| 3 格 | a 1.2（左邊大格，跨兩列）；b、c 1.65 |
| 4 格 | a 2.9；b 1.25；c 1.6；d 2.5 |
| 5 格 | a、b 2.1；c、d、e 1.4 |

圖在格子裡是鋪滿（`object-fit: cover`）。直向或比例不同的時候，照 `comic.js` 那一格的 `focus` 裁，例如 `'62% 40%'` 是臉的位置。所以出圖時臉不要貼著邊。

## 表情（faces.js）

現有六種：
- `proud`：堅定、濃眉壓下來。
- `calm`：半睜、沉穩（國王）。
- `tears`：嚇哭，眼眶一排淚珠加飛出去的淚、一顆汗。
- `shock`：驚醒，白眼、瞳孔一點、眉彈高、驚嚇線、一串淚。
- `tired`：橫線眼加眼袋。
- `dazed`：豆眼、一邊挑眉、一顆汗。

**怎麼運作**：拍之前把模型的兩片眼睛藏起來。從眼睛的骨頭投影出每一隻眼睛在畫面上的中心、大小（眼睛半高 `r`）、頭頂方向、鼻樑在哪一側。拍完、網點之後，用 2D 畫上去。

**新增表情**：在 `FACES` 加一個函式。座標是那一隻眼睛自己的：原點是眼睛中心，−y 是頭頂，+x 是鼻樑那一側，單位是 `r`。左右不對稱的用 `a.i`（第幾隻眼睛）分。畫完照規則 5 自己檢查一次。

## 踩過的坑

- **全黑**：毛皮與王冠的著色器要一張投影深度圖。沒有綁的話，ANGLE 會整個不畫，畫面是一片墨色。攝影棚已經讓 `light/shadow.js` 綁一張空的；新增別的材質時注意這件事。
- **帽簷擋眼睛**：主角戴帽子，從上往下拍時帽簷蓋住眼睛。鏡頭放在眼睛高度或更低，或讓牠抬頭（`headPitch` 負值）。
- **吻部擋眼睛**：模型的眼睛貼在吻部的上角，正面或仰頭時，吻部會擋在眼睛前面。表情是畫在最上層的，擋住的眼睛也照畫，看起來會像眼睛畫在鼻子上。選側一點、低一點的角度；正面特寫用 `eyes: { lift: 0.9, spread: 0.35 }`。
- **側面**：遠的那隻眼睛會自動收掉、不畫。三分之四側時，遠的那隻可能還在、卻疊到吻部上；轉多一點或轉少一點。
- **太暗**：背光時大半落在暗部，網點會很重。用 `light` 把主光轉到鏡頭這一側。
- **檔案大小**：一格 250～600 KB。全部畫完約 15 MB，之後可能要改存 WebP。
- **無頭 Chrome**：`make-comic.mjs` 找系統的 Chrome（或用環境變數 `CHROME` 指定），用的是軟體 GL，拍一格只要幾秒。不要拿它跑遊戲本身，一秒不到一幀。
